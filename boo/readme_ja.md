# 観測者の書の説明書

## 短いまとめ

　観測者の書（The book of Observer）とは私が作ったOberinの補助ツールである。

　任意の期間のログファイルを走査することで、主に以下のようなことができる：

* スキルレベルもしくはクラスレベルが上がった日時を表示する
* スキルレベルが上がった時にどのくらいそのスキルを使用/成功/失敗したかと、その成功率を表示する
* それぞれのスキルをトータルでどのくらい使用/成功/失敗したかと、その成功率を表示する

　これはWindows版もしくはMac版のGoogle Chromeで動作し、FirefoxやSafariでは動かない。多分Microsoft Edgeでは動くかな？

　また、**Logs フォルダがシステムフォルダ内にあると動かない**ので、先にOberinの Config.cfg をいじって Logs フォルダをシステムフォルダの外に置いておかないといけない。

　エンジョイ！

## 長いまとめ

　観測者の書（The book of Observer）とは、Obeirnのログファイルを読み取って情報を表示するツールである。

　任意の期間のログファイルを走査することで、スキルレベルとクラスレベルが上がった日時と、その成功率を表示する。

　ついでにそのスキルをどのくらい/どのように使ったかのデータも出してくれたりするぞ。

1. **前準備：Config.cfg の編集**

    　観測者の書を使うためには、ログファイルが保存されている Logs フォルダを指定して、ツールがログファイルを開けるようにしてやらないといけない。

    　Windows版・Mac版のいずれにおいてもデフォルトでは **Logs フォルダがシステムフォルダ内にあってセキュリティ上の都合でブラウザからアクセスできない**ので、まずはOberinの Config.cfg ファイルを編集して Logs フォルダの場所を変える必要がある。

    　Logs フォルダの場所はデフォルトでは、

    Windows版： `C:\Users\[User Name]\AppData\Local\Oberin_BE\Logs`

    Mac版： `/Users/[User Name]/Library/Application Support/Oberin_BE/Logs`

    （`[User Name]`のところは人によって違うので注意）

    …になっている。

    　ゲームのメニューバーの『`Oberin`』から『`Open Default Config Directory`』を選択すると、これらのデフォルトの Oberin_BE フォルダが開く。

    　Config.cfgをメモ帳とかテキストエディットとかの適当なテキストエディタで開いて、

    > USE_OPTIONAL_PATH=0
    >
    > OPTIONAL_PATH=

    これ（↑）を、この（↓）ように変更する。

    > USE_OPTIONAL_PATH=1
    >
    > OPTIONAL_PATH= `[directory path]`

    　この『`[directory path]`』の部分には任意のフォルダのパスを入れる。デスクトップでもドキュメントフォルダでも好きな場所に適当な名前のフォルダ（例えば『Oberin_BE』とか）を作って、そのフォルダのパスをコピペしよう。

    　Windowsなら作ったフォルダの上で右クリックして『パスをコピー』を選ぶ、Macなら作ったフォルダの上で Contorl＋クリックして『情報を見る』で出てきたウインドウの『場所』の上でまた Contorl＋クリックすればそのフォルダのパスのコピーができるぞ多分。

    　編集した Config.cfg ファイルを保存してからゲームを再起動すると、先ほど Config.cfg 内で指定したフォルダの中にオリジナルの Config.cfg の複製が作られる。

    　ゲームを再起動して、メニューバーの『`Oberin`』から『`Open Optional Config Derectory`』を選択し、さっき作ったフォルダが開いたら準備は完了だ。ここで`Open Optional Config Derectory`がグレーアウトして選べない場合はここまでのどこかで手順を間違えているので、もう一度最初からやり直そう。

    　どうしても上手く行かない時はオリジナルの方の Config.cfg ファイル（つまり『`Open Default Config Directory`』で開く方のフォルダの中のやつ）を削除してからゲームを再起動すると、新しく初期状態の Config.cfg ファイルが作られて全部リセットできるぞ。

1. **前準備：Options の設定を確認**

    　このツールはログファイルを読み取って色々するものなので、そもそもログファイルを保存する設定になっていないと動作しない。

    　ゲーム内のメニューバーの『`Options`』から『`Log Text`』の『`Enabled`』がチェックされていることを確認しておこう。

    　これで指定したフォルダに自動的に新しい Logs フォルダも作られて、その中にログファイルが溜まっていくはずだ。

    　ちなみに『`Split per character`』はオンでもオフでもどちらでも問題ないけど、後でこの設定がオンなのかオフなのかは指定する必要があるぞ。

1. **Logs フォルダの登録と各種設定**

    　ここまでできたら、このツールの『フォルダを選択』ボタンをクリックする。

    　するとフォルダの選択画面が出てくるので、指定したフォルダの中にある Logs フォルダを指定しよう。

    　次に、走査するログファイルの期間を指定する。物凄く過去の日付と物凄く未来の日付を指定すると実質的に Logs フォルダの全ログファイルを走査することができるけど、365日×20年分＝7300ファイルとか一気に読み込んでもツールが耐えられるのかは試してないぞ。

    　さらに、精査したいキャラクターの名前と『`Options`』の『`Log Text`』のところで『`Logs are splited per name`』がチェックされているかどうかを指定する。それがオンだったらこっちもオンにしよう。

    　最後に、追加の解析情報を表示するかどうかを選択しよう。項目は見れば分かると思うけど、一応解説しておくと：

    * **Take/Catch**: Lumberjacking/Mining/Fishingの拾得物のカウント。これで誰かに「お前は今まで釣り上げたTroutの数を覚えているのか？」とか聞かれても即座に答えられるから安心だ。
    * **Potion**: Alchemy/○○で作ったPotion、もしくはEnchantingの生成物のカウント。誰かに「お前は今まで作ったPotionの数を」以下略。
    * **Spell**: Magery/○○で唱えた魔法のカウント。誰かに「お前は今まで」以下略。
    * **Reagent**: Alchemy/○○およびMagery/○○で消費した試薬のカウント。誰かに「お前は」以下略。

    　ここまで全部できたら、最後に『集計開始』ボタンを押す。すると下の集計結果にずらーっとデータが表示されるぞ。

## 注意

　Blacksmithing/Tailoring/Thinkering/Woodcraftingおよび一部のEnchantingは制作時のログの見分けが付かないため、直前に装備した道具を見てどのスキルを使ったのか判別している。これはスキル使用によって自動的に道具を装備する限り有効に動くはずだけど、敢えて手動で道具を装備してしまうとログに表示されないため集計ミスを起こすので注意しよう。

　AnatomyやMeditation・Tamingは特にスキル経験値的には無意味と思われるデータを集計して表示しているが、これはわざとである。

　現時点ではSpecial/○○やPoisoning/Stealth/Trackingには対応していない。何故なら私がDruidのキャラクターしか持っていないため、他のクラスの固有スキルのログがどうなっているのか分からないからだ。そのうち何とかする。

　このツールは『どのくらいでレベルアップしたのか？』を検証するために作られたものであり、作者の個人的なポリシーにより **『あとどのくらいでレベルアップするか？』には対応しない**（表示されたデータから一応そういうのを計算することはできるけど手作業でやってくれ）。スキルレベルなんて適当にやってりゃそのうち勝手に上がるもんだよ。

## 余談

　このツールはFandomのOberin Wikiで「レベル1の収集スキルの成功率が10％しかない」と書かれていたのに実際にやってみたらどう見ても25％はあったため、ちゃんとしたデータをとるために作りました。

　個人的にはスキルのレベル上げを意識した作業プレイとかはしない主義なんだけど、それはそれとしてそういうのが気になるという意見もまあ分かるので、それならまあ自分だけで使ってないで一般公開はしておいても良いかなって。

　このツールがあなたのOberinライフの助けになるなら幸いです。でも根を詰めた作業プレイは程々にナ。
